# Chat network marks

From Simple Icons 16.38.1 (https://simpleicons.org, `icons/<slug>.svg`), CC0 1.0; the
`<title>` and `role` are taken out. The marks are their owners' trademarks, shown only to say which
network a chat is on. Their brand colors are in `NETWORK_MARKS` (`src/lib.rs`). Slack, LinkedIn and
Google Voice have no mark: that version's `data/simple-icons.json` lists none for them.
