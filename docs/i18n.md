# Interface language

The interface is English and Polish. It follows the system language: Android's
locale, on desktop the first set of `LC_ALL`, `LC_MESSAGES`, `LANG`. Only `pl`
gives Polish; everything else is English. There is no switch in the app.

## How it works

- English text in the code is the key: `t!("Mute")`, `t!("Could not leave the chat: {error}", error = e)`.
  `src/i18n/pl.rs` holds the Polish for each key; a missing key shows English.
- Counts: `tn!(n, "Forwarded to {n} chat", "Forwarded to {n} chats")`. Polish picks one of three
  forms: 1; ending in 2-4 except 12-14; the rest.
- Constant tables mark their text with `n_!("...")` and translate it where it
  is shown, with `tr()`.
- One English word with two meanings gets a context after `|`, dropped in
  English: `"Archive"` (the list, `Archiwum`) and `"Archive|verb"`
  (`Archiwizuj`); `"System"` (theme, `Systemowy`) and `"System|emoji"`
  (`Systemowe`).
- Dates and weekdays: `i18n::date`, `date_short`, `weekday`, `weekday_short`.
- Android's own screens (notifications, the background service, the video
  player, the screen lock prompt) use `res/values/strings.xml` and
  `res/values-pl/strings.xml`.
- `src/i18n/tests.rs` fails when a key in the code has no Polish, when
  `pl.rs` holds a key the code no longer uses, or when a Polish text loses a
  `{placeholder}`.

Adding a string: write it as `t!("...")`, add the Polish to `pl.rs`, run the
tests.

## What stays English

- Log lines and error chains meant for debugging.
- Protocol values and anything other people receive: message bodies, the
  location text, forwarded text, file names of voice messages.
- Names: Unisend, Beeper, Matrix, WhatsApp, Signal, Messenger, Instagram,
  Telegram, KLIPY, the other networks.

Sentences about what the reader did use both genders in one word:
`rozpocząłeś(-aś)`, `zmieniłeś(-aś)`. Sentences about someone else use the
past tense without a gender where Polish allows it (`{actor} zmienił(a) nazwę`).
Address the reader as `Ty`/`Twoje`, capitalised, as Signal and WhatsApp do.
